# Wireframes (Day 1)

Low-fi page list to guide component building. Sketch these on paper or Figma —
the goal is agreeing on pages before writing code.

## Public
- Login page (email, password, "register" link)
- Register page (name, email, password, role — role defaults to "customer")

## Customer
- Dashboard: list of my policies (card per policy: type, number, status, expiry)
- Policy detail: premium amount, dates, "Download document" and "Submit claim" buttons
- Submit claim form: amount, reason, file upload
- Claim history table: status badges (pending/approved/rejected)
- Payment history table

## Agent
- Customer list (search + register new customer button)
- Create policy form (select customer, policy type, premium, dates)
- Claims queue: pending claims, view documents, approve/reject buttons

## Admin
- Dashboard: charts (active policies, claim stats, premium collection, customer growth)
- Employee management table
- System settings page
